# 离线重力参数辨识

仅播放辨识用的轨迹，不采集数据：

```bash
python3 -m piper.sim.estimate.trajectory_demo
```

从 home 出发，依次经过六个固定种子的随机姿态，再回到 home 循环。每段用五次多项式平滑移动 3 秒，到位后停留 2 秒，起止速度和加速度为零。`trajectory()` 返回目标角度、速度和加速度；demo 使用位置接口跟踪目标角度，绿球显示目标末端位置。这里演示的是重力辨识所需的“移动—静止”轨迹，不进行辨识、数据记录或可辨识性优化。

在项目根目录直接运行，无命令行参数：

```bash
python3 -m piper.sim.estimate.gravity_identification
```

依赖：`pin`、`mujoco`、`numpy`。

脚本随机修改 `link2` 的质量，其他参数保持已知。MuJoCo 用原始模型生成 300 组静态姿态和重力力矩，前 200 组用于辨识，后 100 组用于验证。

质心固定时，重力力矩对质量是线性的。用 Pinocchio 计算质量增加 1 kg 前后的力矩差 `A`，再求解 `A * delta_m = 测量力矩 - 初始预测力矩`。这与单质量的重力回归等价，辨识过程不读取原始质量。

终端直接打印原始、扰动、辨识质量，以及独立测试集上的重力力矩 RMSE。这里仅辨识一个质量，不同时辨识全部质量或长度。

## 双向启动摩擦估计

```bash
python3 -m piper.sim.estimate.friction_estimation --joint 3
```

无窗口离线运行共用的 `piper.estimate.friction_estimator.FrictionEstimator`，不连接真机、不读取反馈力矩。MuJoCo 使用带摩擦和惯性偏差的 `arm_mujoco.xml`，重力补偿仍由原 `arm_official.xml` 计算。每档增加 0.05 N·m，记下启动阈值后低速走过 5.2°，位置模式慢速回位，再测反向。回位阶段使用较强的位置伺服；测量阶段关闭模型自动重力补偿和测试轴位置弹簧。仿真步长 0.001 s，估计器按仿真时间推进，无需等待同等墙钟时间。

2026-11-26，J3 单次离线结果：

| 项目 | 结果 |
| --- | --- |
| 正向启动附加力矩 | +0.250 N·m |
| 反向启动附加力矩 | −0.700 N·m |
| 摩擦估计（半差） | 0.475 N·m |
| 模型设定干摩擦 | 0.440 N·m |
| 双向阈值半和 | −0.225 N·m |
| 全过程最大关节速度 | 0.6445°/s |
| 正／反向行程（相对起点） | 5.3026°／5.2601° |
| 累计仿真时间 | 48.995 s |

双向阈值不对称，半和包含重力模型失配等偏置。估计仍受 0.05 N·m 档位、启动判据和运动中的动力学影响，并非严格等于模型参数。本次验证的是 J3，未运行真机。
